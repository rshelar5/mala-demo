# Mala

A mantra chanting counter. One screen, mobile first, works offline.

- Infinity sign counts to 108; a glowing point travels the figure once per chant.
- **Guided** mode paces you; **beads** mode marks a whole mala with one button.
- Two mantras, three scripts (Devanagari, Malayalam, English), recited audio.
- Lifetime totals saved locally. Long-press the totals to reset.

Static HTML, CSS and JavaScript. No backend, no build step.
